The PatCom (Patrol Commander) system is a comprehensive AI behavior management solution for Antistasi, providing intelligent patrol patterns, dynamic combat responses, and realistic civilian interactions. Every function includes detailed code examples showing exactly how it works.

🎯 Key Features

  • Dynamic AI Behavior: Context-aware patrol patterns that adapt to environment and threats
  • Realistic Combat Response: Intelligent switching between patrol, attack, and defense modes
  • Civilian Interaction System: Immersive civilian behaviors with dialogue and reactions
  • Advanced Artillery Support: Coordinated fire missions with safety checks and reload management
  • Modular Architecture: Clean separation of concerns with extensible design
  • Performance Optimized: Efficient algorithms with minimal performance impact
  • Comprehensive Validation: Multi-layer error checking and edge case handling
  • Debug Visualization: 3D debug tools for AI pathfinding and state monitoring

🏗️ System Architecture

The PatCom system uses a hierarchical architecture with clear separation between strategic command, tactical execution, and environmental interaction. Data flows through a structured pipeline from threat detection to behavioral response.

AI Behavior Pipeline: ├── Threat Detection (fn_patrolGetEnemies) ├── Command Logic (fn_patrolCommander) ├── Behavior Execution (fn_patrolArea/fn_patrolAttack/fn_patrolDefend) ├── Environmental Adaptation (fn_patrolHandleFormation) ├── Static Weapon Management (fn_patrolArmStatics) └── Debug Visualization (fn_debugText3D/fn_debug3DPath) Civilian System: ├── Ambient Population (fn_createAmbientCiv) ├── Behavior Initialization (fn_civilianInitEH) ├── Interaction Handling (fn_dialogCiv) ├── Reaction System (fn_civilianFiredNearEH) └── Audio Management (fn_createCivilianTracks) Artillery System: ├── Battery Registration (fn_artilleryAdd) ├── Safety Validation (fn_artilleryDangerClose) ├── Fire Mission Coordination (fn_artilleryFireMission) └── Weapon Management (fn_getReloadTime)

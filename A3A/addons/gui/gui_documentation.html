📋 System Overview

The A3A GUI system provides a comprehensive set of dialog functions for managing the user interface in Antistasi. It covers game initialization, player management, commander operations, and specialized tools for building and logistics.

🎯 Key Features

  • Multi-Dialog Architecture: Separate dialogs for setup, main menu, and specialized tools.
  • Tab-Based Navigation: Modular tab systems for organized UI content.
  • Dynamic UI Generation: Controls created programmatically based on data.
  • Event-Driven Interaction: Mouse handlers, button clicks, and map interactions.
  • Resource Management: Visual feedback for money, HR, and other resources.

🖥️ Setup Dialogs (7 Functions)

Functions handling game initialization, configuration, and save management.

fn_setupConfirmDialog.sqf
Scheduled (onLoad) Unscheduled
What it does: Handles initialization and tab switching on the setup confirmation dialog. Manages the dialog that appears when users are about to make changes or start a new game.
How it does that:
• Manages confirmation dialog modes (onLoad, confirm)
• Sets confirmation text from parent dialog's confirmData variable
• Executes confirmed actions via spawned functions (requires spawn for displayCtrl compatibility)
• Closes dialog after action execution

Key Logic:
params ["_mode", "_params"];
private _display = findDisplay A3A_IDD_SETUPCONFIRMDIALOG;
private _parent = displayParent _display;
switch (_mode) do { ... };
Dependencies:
• A3A_IDD_SETUPCONFIRMDIALOG - Dialog ID constant
• A3A_IDC_SETUP_CONFIRMTEXT - Text control ID
• Setup Dialog - Parent for data retrieval
• spawn - Required for displayCtrl operations

• A3A_SETUP_CONFIGFILE - Config path
• A3A_IDC_SETUP_ADDONVICSBOX, A3A_IDC_SETUP_DLCBOX - Control IDs

🔧 Utility Functions (2 Functions)

Helper functions for UI calculations and color conversions.

fn_sizeOf.sqf
Unscheduled
What it does: Calculates the bounding-box diameter of a vehicle class for accurate UI and placement sizing.
How it does that:
• Caching: Uses A3A_GUI_sizeOf_cache HashMap for performance
• Direct Measurement: Uses sizeOf engine command if non-zero
• Fallback Creation: Creates temporary vehicle if sizeOf returns 0
• Cleanup: Deletes temporary vehicle after measurement

Usage:
["C_Offroad_01_F"] call A3A_GUI_fnc_sizeOf; // 11.4563
Dependencies:
• A3A_GUI_sizeOf_cache - HashMap cache
• sizeOf - Engine command
• createVehicle - Fallback measurement
• deleteVehicle - Cleanup
fn_configColorToArray.sqf
Unscheduled
What it does: Converts config color values (e.g., {1,0,0,1}) into SQF arrays ([1,0,0,1]).
How it does that:
• String Conversion: Converts config color to string representation
• Brace Extraction: Removes outer braces
• Compile Execution: Compiles and executes the string as an array

Example:
[configFile >> "CfgMarkerColors" >> "ColorRed"] call A3A_fnc_configColorToArray
Returns: [1, 0, 0, 1]
Dependencies:
• str - String conversion
• compile - Array creation
• No external dependencies - Pure SQF utility

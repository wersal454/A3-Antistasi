        if(_add > 0)then{
            _ctrlList lnbsettext [[_lbcursel,2],str (_amountOld + _count)];
            [_index, _item, _count]call jn_fnc_arsanel_removeItem;
        }else{
            _ctrlList lnbsettext [[_lbcursel,2],str (_amountOld - _count)];
            [_index, _item, _count] call jn_fnc_arsanel_addItem;
        };
    };

    _load = switch _selected do{
        case IDC_RSCDISPLAYARSENAL_TAB_UNIFORM: {loaduniform player};
        case IDC_RSCDISPLAYARSENAL_TAB_VEST: {loadvest player};
        case IDC_RSCDISPLAYARSENAL_TAB_BACKPACK: {loadbackpack player};
    };

    _ctrlLoadCargo progresssetposition _load;

    ["SelectItemRight",[_display,_ctrlList,_index]] call jn_fnc_arsanel;
};

Line-by-line explanation

  1. _display = _this select 0; — the UI display object passed by caller.
  2. _add = _this select 1; — integer: +1 for add, -1 for remove.
  3. Find which left-tab is active (uniform/vest/backpack) by checking enabled left list controls; stores in _selected.
  4. Find which right list is active and its current cursor selection row; stores control in _ctrlList, tab index in _index and row in _lbcursel.
  5. Read the selected list item: _dataStr = _ctrlList lnbData [_lbcursel,0]; _data = call compile _dataStr; — lnbData stores a stringified array, compile to evaluate into array; then _item/_amount extracted.
  6. Initialize local state: _load/_items/_itemChanged and get _ctrlLoadCargo control for the load progress bar.
  7. Save old container load via switch on _selected (loaduniform/loadvest/loadbackpack).
  8. Set default change count _count = 1 (magazine handling may override).
  9. Guard: if the action makes sense (amount available or removing) then proceed.
  10. If adding (_add > 0): enforce non-member min via _minItemsMember and show message + exit if violation. For magazines adjust _count to magazine bullet count and cap by available amount. Determine container and check canAddItemToX, then add mags via addMagazineAmmoCargo; for non-mag items call addItemToUniform/addItemToVest/addItemToBackpack.
  11. If removing: for magazines, read container magazines, ensure item present, clear container then rebuild mags skipping the one removed (preserves other mags); for non-mag items call removeItemFromUniform/removeItemFromVest/removeItemFromBackpack.
  12. After add/remove attempts, compute new load and if it changed compared to saved _loadOld then update the UI counter and notify the arsenal system: call removeItem (when adding to container) or addItem (when removing from container) with [_index,_item,_count]. These calls update the global JNA data and remoteExec clients as needed.
  13. Recompute current load, set progress bar position with progresssetposition, and call ["SelectItemRight",[_display,_ctrlList,_index]] to refresh right-side selection UI/colours.

Edge cases & synchronization

  • Uses compile on stored lnbData; ensure data strings are trusted (they originate from the local UI dataset).
  • Membership limits protected: players failing the member check cannot add items below configured minima.
  • Magazine handling carefully reconstructs container magazines to avoid leaving inconsistent ammo counts.
  • After local inventory modifications, calls to jn_fnc_arsanel_addItem/removeItem notify server/clients to keep global arsenal lists synchronized.
  • UI feedback updates only when actual load change occurred; avoids spurious updates.

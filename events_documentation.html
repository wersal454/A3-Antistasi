The A3A Event System is a lightweight, extensible event handling framework for the A3A mod. It uses a central HashMap registry to manage event listeners, allowing decoupled communication between different systems. It supports adding/removing listeners by unique ID and triggering events with arbitrary arguments.

🎯 Key Features

  • Dynamic Registry: HashMap-based storage for O(1) listener lookup.
  • Unique IDs: Prevents duplicate listeners by enforcing unique identifiers.
  • Type Safety: Callbacks can be Code blocks or String function names.
  • Argument Validation: Optional compile-time validation against config definitions.
  • Flexible Callbacks: Supports both direct code execution and string-based function calls (resolving mission/ui namespace).

⚙️ System Configuration

1. script_component.hpp (Defines)
What it defines:
• Component name and macro includes
#define COMPONENT events
• Sets up the relative path to the core mod includes
#include "\x\A3A\addons\core\Includes\script_mod.hpp"
How it works:
• Defines the component name
#define COMPONENT events
• Includes the main mod header file
#include "\x\A3A\addons\core\Includes\script_mod.hpp"
• This header typically defines ADDON, VERSION_CONFIG, and other necessary macros used in CfgPatches.
2. config.cpp (CfgPatches)
What it defines:
• Addon metadata and dependencies
class ADDON { name = COMPONENT_NAME; requiredVersion = REQUIRED_VERSION; ... };
• Loads the Events config class under A3A
class A3A { #include "Events.hpp" ... };
Structure:
• CfgPatches Class: Defines the addon 'events' with metadata.
• CfgFunctions Class: Defines function paths for 'functions'.
• A3A Class: Includes 'Events.hpp' containing the registry definitions.
3. CfgFunctions
What it defines:
• Maps function names to file paths
class functions { file = QPATHTOFOLDER(functions); class addEventListener {}; ... };
• Registers 5 functions: addEventListener, removeAllEventListeners, removeEventListener, triggerEvent, validateEventArguments
Functions List:
• addEventListener -> functions\fn_addEventListener.sqf
• removeAllEventListeners -> functions\fn_removeAllEventListeners.sqf
• removeEventListener -> functions\fn_removeEventListener.sqf
• triggerEvent -> functions\fn_triggerEvent.sqf
• validateEventArguments -> functions\fn_validateEventArguments.sqf

🔧 Core Functions (4 functions)

1. fn_addEventListener.sqf
What it does:
• Adds a listener to an event, allowing you to trigger functions when that event occurs
["AIVehInit", "A3A_Events_example", {systemChat "Example event listener triggered!"}] call A3A_Events_fnc_addEventListener;
• Accepts String or Code callbacks
// Creates a new entry in GVAR(EventRegistry) hashmap
How it does that:
• Validates input parameters
params [["_event", "", [""]], ["_id", "", [""]], ["_callback", {}, ["", {}]]];
• Initializes global Event Registry if missing
if (isNil QGVAR(EventRegistry)) then { GVAR(EventRegistry) = createHashMap; };
• Ensures a hashmap exists for the specific event
if !(_event in GVAR(EventRegistry)) then { GVAR(EventRegistry) set [_event, createHashMap]; };
• Logs a warning if overwriting an existing listener ID
Info_4("Event listener overwritten | Event: %1 ID: %2 | Old -> Callback: %3 | New -> CallBack: %4", ...);
• Stores the callback in the registry
(GVAR(EventRegistry) get _event) set [_id, _callback];
• Returns array for removal
[_event, _id];
Dependencies:
• GVAR(EventRegistry) - Global HashMap storing events.
• Info_4 - Logging macro.
2. fn_removeAllEventListeners.sqf
What it does:
• Removes all event listeners subscribed to a particular event
["AIVehInit"] call A3A_Events_fnc_removeAllEventListeners;
• Effectively wipes the callback list for that event
// Sets the event map to an empty array
How it does that:
• Validates event parameter
params [["_event", "", [""]]];
• Checks if Event Registry exists
if (isNil QGVAR(EventRegistry)) exitWith { Warning_1(...) };
• Clears all listeners for the event by setting it to empty array
if (_event in GVAR(EventRegistry)) then { GVAR(EventRegistry) set [_event, []]; };
• Warns if trying to remove from non-existent event
Warning_1("No listeners for event %1 exists", _event)
Dependencies:
• GVAR(EventRegistry) - Global HashMap storage.
3. fn_removeEventListener.sqf
What it does:
• Removes a specific event listener
["AIVehInit", "A3A_Events_example"] call A3A_Events_fnc_removeEventListener;
• Targeted removal using the unique ID provided during addition
// Deletes specific entry from event map
How it does that:
• Validates event and ID parameters
params [["_event", "", [""]], ["_id", "", [""]]];
• Checks registry existence
if (isNil QGVAR(EventRegistry)) exitWith { ... };
• Checks if event exists and listener ID is present
if (_event in GVAR(EventRegistry) && { !isNil { (GVAR(EventRegistry) get _event) get _id } }) then { ... };
• Deletes the specific listener
(GVAR(EventRegistry) get _event) deleteAt _id;
• Warns if target not found
Warning_2("No listener for event %1 with ID %2 exists", _event, _id)
Dependencies:
• GVAR(EventRegistry) - Global HashMap storage.
4. fn_triggerEvent.sqf
What it does:
• Triggers an event
["AIVehInit", [_veh, _side]] call A3A_Events_fnc_triggerEvent;
• Executes all callbacks subscribed to the event with provided arguments
// Iterates listeners and passes arguments
How it does that:
• Extracts event and arguments
params [["_event", "", [""]], ["_arguments", [], [[]]]];
• Initializes registry if missing
if (isNil QGVAR(EventRegistry)) exitWith { GVAR(EventRegistry) = createHashMap; };
• Validates event class exists in Config
if (!isClass (configFile/"A3A"/"Events"/_event)) exitWith { Warning_1(...) };
• Optional argument validation (Compile time)
#ifdef VALIDATE_EVENT_ARGUMENTS if !(_this call FUNC(validateEventArguments)) exitWith {}; #endif
• Iterates through all listeners for the event
{ ... } forEach (GVAR(EventRegistry) getOrDefault [_event, createHashMap]);
• Handles Code vs String callbacks
if (_y isEqualType {}) then {_arguments call _y} else { private _func = missionNamespace getVariable [_y, uiNamespace getVariable _y]; ... };
Dependencies:
• GVAR(EventRegistry) - Global HashMap storage.
• FUNC(validateEventArguments) - Optional validation logic.
• missionNamespace / uiNamespace - For resolving string function names.

📜 Event Registry Reference

Defined in Events.hpp. These classes define the expected arguments and behavior for specific events.

AIVehInit
Triggered when an AI vehicle is initialized.
Arguments:
• _0 (OBJECT): Vehicle being initialized
• _1 (SIDE): Side the vehicle belongs to

Flags:
• isLocal = 1 (Triggered on local machine)
HQPlaced
Triggered when the Headquarters is placed.
Arguments:
• _0 (ARRAY): Position of new HQ

Flags:
• isLocal = 1
RebelControlCreated
Triggered when a rebel control element (marker) is created.
Arguments:
• _0 (STRING): Marker
• _1 (STRING): Control Type

Flags:
• isLocal = 1
markerChange
Triggered when a marker changes ownership (winner side).
Arguments:
• _0 (STRING): Marker
• _1 (SIDE): Side of winner

Flags:
• isLocal = 1
vehicleBoxRestore
Triggered to restore a vehicle box (ammocrate/supply).
Arguments:
• _0 (ARRAY): Position of effect center

Flags:
• isLocal = 1
civInit
Triggered when a civilian unit is initialized.
Arguments:
• _0 (OBJECT): Unit being initialized

Flags:
• isLocal = 1
civVehInit
Triggered when a civilian vehicle is initialized.
Arguments:
• _0 (OBJECT): civ vehicle being initialized

Flags:
• isLocal = 1
locationSpawned
Triggered when a game location (city/outpost) spawns or changes state.
Arguments:
• _0 (STRING): Marker
• _1 (STRING): Location type
• _2 (BOOL): Is spawning

Flags:
• isLocal = 1
AIInit
Triggered when an AI unit is initialized.
Arguments:
• _0 (OBJECT): Unit being initialized
• _1 (SIDE): Side of the unit
• _2 (STRING): Marker the unit belongs to (Optional)
• _3 (BOOL): If the unit is a spawner

Flags:
• isLocal = 1
Undercover
Triggered related to undercover status changes.
Arguments:
• _0 (STRING): Reason for undercover break (empty on init) (Optional)

Flags:
• isLocal = 1
